1. 수집하는 정보

항목 수집 방법 목적
이메일 주소 가입·로그인할 때 이용자가 입력 계정 식별, 로그인 코드 발송
목표·할 일·루틴과 완료 기록 이용자가 앱에 입력 기기 간 동기화, 서비스 제공
시간대, 주 시작 요일 시간대는 기기 설정에서 자동으로 읽고, 주 시작 요일은 이용자가 선택 날짜를 올바르게 계산하고 캘린더를 표시

앱은 이름, 전화번호, 위치, 연락처, 사진 등 위 표에 없는 정보를 요청하지 않습니다. 이용자는 비밀번호 없이 이메일로 받은 일회용 코드로 로그인합니다.

2. 이용 목적

  • 계정을 만들고 로그인하도록 하기 위해
  • 이용자가 입력한 내용을 저장하고 같은 계정의 여러 Mac에 동기화하기 위해
  • 이용자 문의에 답하기 위해

수집한 정보를 광고, 마케팅, 프로필 분석에 쓰지 않습니다.

3. 추적과 광고

앱에는 광고, 분석(애널리틱스), 추적 도구가 없습니다. 다른 회사의 앱이나 웹사이트에서 수집한 정보와 결합하지 않으며, 이용자를 추적(tracking)하지 않습니다.

4. 보관과 삭제

  • 정보는 계정이 유지되는 동안 보관합니다.
  • 앱의 설정 → 계정 삭제에서 계정을 삭제하면 계정과 목표·할 일·루틴·완료 기록이 서버에서 삭제됩니다.
  • [[TODO: 데이터베이스 백업에 남는 사본의 보관 기간 확인 후 기재, 법령상 보관 의무가 있는지 검토]]

앱이 기기에 저장한 로그인 정보와 캐시는 로그아웃하거나 계정을 삭제하면 해당 기기에서 지워집니다.

7. 안전성 확보 조치

  • 앱과 서버 사이의 통신은 HTTPS로 암호화합니다.
