# 모바일 화면 스펙 (iOS)

> v2(Expo iOS) 전용입니다. 데스크톱 화면은 `screens.md`, 공통 값은 `tokens.md`·`components.md`를 그대로 씁니다.
> 요구사항 ID는 `docs/01-requirements.md`, 단계는 `docs/11-v2-plan.md` §3 기준.
> 각 화면 이름 옆의 괄호는 디자인 캔버스 "Nodii 디자인"의 **모바일 (iOS)** 페이지 아트보드 이름입니다. 기준 크기는 390×844(iPhone 13/14)입니다.

## 0. 원칙

모바일은 **새 디자인이 아니라 같은 디자인의 다른 몸**입니다.

데스크톱에서 **그대로 가져오는 것** (새로 만들지 않습니다)

- `tokens.md`의 색·글꼴·모서리·모션 값 전부. 색은 목표 색만 가지고 나머지는 먹과 회색입니다.
- 목표 이름표: `chip` 회색 알약 + 목표 색 점 + `goalInk` 글자 + 먹색 `+`. 체크는 **싹이**(새싹) 모양: 안 한 일은 `box`로 채운 동그란 씨앗, 끝내면 끝내면 목표 색으로 채우고 표시는 `checkColor` (디자인 시스템 v2).
- 캘린더 도장(역시 싹이 모양, 다 끝낸 날만 잎이 돋음): 다 끝낸 날은 `stampFill`(그날 목표 색 블록) + 흰 체크 / 남은 지난날·오늘은 `box`에 개수 / 앞날·빈 날은 `stamp-soft`.
- 할 일 줄의 구성(체크 · 제목 · 끝낸 줄은 취소선 없이 `ink-2`), 먹색 알약 기본 버튼, 알약 세그먼트, 알약 실행 취소 토스트, 확인 창.
- 문구. `screens.md`에 있는 말은 그대로 씁니다.

모바일에서 **바꾸는 것** (v2 계획 §2.3)

| 데스크톱 | 모바일 | 이유 |
| --- | --- | --- |
| 사이드바 캘린더(380px 고정) | 주간 스트립, W / M으로 월간 전환 | 폭이 없습니다 |
| 사이드바는 고정, 목록만 스크롤 | 캘린더도 목록과 함께 스크롤 | 세로 공간 |
| 호버로 드러나는 `⋯` | 왼쪽/오른쪽 밀기 + 길게 누르기 | 호버가 없습니다 |
| 우클릭 컨텍스트 메뉴 | 길게 누르기 → 바텀 액션 시트 | 우클릭이 없습니다 |
| 시트·모달(창 위에서 내려옴) | 바텀 시트(아래에서 올라옴) | iOS 관례 |
| 날짜 헤더(큰 제목 + 개수 요약) | 없음. 날짜는 캘린더가 알려 줍니다 | 세로 공간 |
| 단축키(`⌘N`, `←/→`) | 없음. 대신 날짜는 스트립 탭과 좌우 스와이프 | 키보드가 없습니다 |
| 키보드 포커스 링(`ink` 2px) | 없음. 입력 중 표시는 먹색 테두리와 캐럿 | 터치만 씁니다 |

**할 일 추가는 데스크톱과 똑같습니다.** 목표 이름표의 `+`를 누르면 그 목표 자리에 입력 줄이 열립니다. 하단 고정 추가 바나 떠 있는 `+` 버튼은 두지 않습니다.

## 1. 공통 규칙

**safe area** — 위 47pt(상태 표시줄), 아래 34pt(홈 인디케이터)를 비웁니다. 하단 고정 바는 콘텐츠 영역 아래 34pt를 더한 높이를 차지하고, 스크롤 영역에는 그만큼 아래 여백을 둡니다. 스크롤 내용이 고정 바 밑으로 사라지게 두지 않습니다.

**터치 영역** — 누를 수 있는 것은 모두 44×44pt 이상입니다. 글리프 자체는 작아도(체크 박스 24px, 아이콘 20px) 바깥을 음수 margin으로 넓혀 44pt를 채웁니다. 서로 다른 동작 사이는 8pt 이상 띄웁니다.

**누름 피드백** — 모든 누를 수 있는 요소에 120ms 안에 보이는 반응(투명도 0.55 또는 `scale(0.88)`)을 둡니다. 레이아웃을 흔드는 반응은 금지입니다. `prefers-reduced-motion`에서는 transition을 끕니다.

**글자 크기** — 본문 16px(데스크톱 15px보다 한 단 큽니다), 큰 제목 28px/-0.7px, 보조 13~14px. 12px 미만은 쓰지 않습니다. Dynamic Type을 켠 기기에서 줄이 깨지지 않게 높이는 `min-height`로 둡니다.

**내비게이션** — 탭 막대는 두지 않습니다. "오늘" 한 화면이 중심이고, 관리 화면은 설정 글리프와 메뉴에서 밀어 넣습니다(push). 뒤로 가기는 왼쪽 위 글리프 + 라벨("‹ 오늘")과 가장자리 스와이프 둘 다 됩니다.

**바텀 시트** — 위 모서리 22, 손잡이 36×5(`mix(bg, ink, 0.2)`), 뒤는 `scrim`. 시트 안의 취소는 왼쪽 위 글자 버튼, 저장은 오른쪽 위 굵은 글자 버튼입니다. 시트를 아래로 밀면 닫히고, 입력 중이면 "저장하지 않고 닫을까요?"를 먼저 묻습니다.

**제스처 대체 경로** — 밀기로 되는 일은 **반드시** 길게 누르기 메뉴에도 있습니다. 손 떨림이나 접근성 설정으로 밀기를 못 하는 사람이 막히면 안 됩니다.

**포커스 표시** — 파란 포커스 링은 쓰지 않습니다. 터치 기기에는 키보드 포커스가 없고, 데스크톱에서 온 링이 목표 색과 부딪힙니다. 입력 중인 칸은 1.5px 먹색 테두리와 목표 색 캐럿으로만 알립니다. 누름 피드백이 "지금 이걸 눌렀다"를 대신합니다.

**상태 표시줄** — 흰색으로 고정하지 않습니다. 바로 아래 구역의 배경을 그대로 이어받습니다(v2에서는 모든 화면 바탕이 `bg` 하나라 상태 표시줄도 `bg`이고, 시트가 덮을 때만 스크림을 따릅니다). 시계와 배터리 글자색은 `ink`입니다.

**접근성** — 라이트·다크 모두 본문 4.5:1 이상(실제로 16.4~17.8:1), 목표 이름표 글자 4.5:1 이상, 체크 표시 3:1 이상을 `goalInk`·`checkColor`가 보장합니다. 아이콘 단독 버튼에는 `accessibilityLabel`을 답니다. 구분선은 두 테마에서 모두 보이는 `line`을 씁니다.

## 2. 화면

### 로그인 (`MobileLogin`)

- 데스크톱 `Login`과 같은 2단계(이메일 → 6자리 코드)입니다. 문구도 같습니다.
- 위에 목표 색 사각형 4개(3개 채움 + 1개 테두리), 제목 28px, 설명 16px.
- 입력칸 높이 52, 모서리 12. 입력 중에는 1.5px 먹색 테두리와 캐럿만 씁니다(파란 링 없음). 기본 버튼은 가로 전체, 높이 52, 모서리 14.
- 코드 단계는 6칸 입력에 `autocomplete="one-time-code"`를 걸어 문자 자동완성이 바로 채우게 합니다.
- 키보드가 올라오면 화면을 위로 밀어 입력칸을 띄웁니다(M1).

### 오늘 (`MobileToday`, 다크는 `MobileTodayDark`)

```
┌──────────────────────────────┐
│ 9:41                   ▮▮ ▮  │  상태 표시줄 47 (side)
│ 2026년 9월  오늘 [W M] ⋯ ☰   │  상단 줄 44 (side, 고정)
├──────────────────────────────┤  ↓ 여기부터 함께 스크롤
│ 일 월 화 수 목 금 토          │  주간 스트립 (side 배경)
│ ✓  1  ✓  2  4  2             │   도장 24
│ 13 14 15 16 ⬤17 18 19        │   날짜 알약
│ (공부 +)                      │  목표 이름표 36, + 가 추가 버튼
│  ☑ 영어 단어 30개              │  줄 52
│  ☑ 알고리즘 2문제              │
│  ☐ OS 과제 3장 정리            │
│ (운동 +)                      │
│  ☐ 러닝 5km                   │
│  ⊖ 스트레칭 10분       건너뜀  │
│ (할 일 +)                     │
│  ☐ 장보기                     │
│  ☐ 택배 반품 접수              │
│                              │  safe area 34
└──────────────────────────────┘
```

- **고정되는 것은 상태 표시줄과 상단 줄뿐입니다.** 캘린더는 목록과 한 덩어리로 스크롤됩니다. 위로 올리면 목록이 화면을 다 씁니다.
- 상단 줄: 왼쪽에 월 제목(20/700). 오른쪽에 [오늘] · [W | M] · `⋯` · 설정 글리프.
  - [오늘]은 시안과 같은 **회색 알약 보조 버튼**입니다(2026-10-27 사용자 결정). 주간·월간 모두 `chip` 바탕 + `ink` 글자(14/800), 테두리 없음, 반지름 999, 높이 36, 좌우 여백 12입니다. 최소 너비 44와 위아래 4pt 확장 영역으로 44pt 터치 높이를 확보하고, 누르면 불투명도 0.55로 반응합니다. 라이트·다크 모두 해당 테마의 `chip`/`ink`를 씁니다.
  - [W | M]은 주간·월간 전환입니다. `chip` 알약 트랙 위에 고른 쪽만 `ink` 원 + `bg` 글자로 띄웁니다. 화살표(`⌃`/`⌄`)는 쓰지 않습니다.
  - `⋯`는 하루 메뉴입니다(`MobileDayMenu`). 데스크톱 날짜 헤더의 `⋯`가 여기로 옮겨 왔습니다.
- 큰 날짜 제목과 "N개 중 M개 완료" 요약은 두지 않습니다. 선택한 날짜는 스트립의 먹색 알약이, 남은 개수는 그날의 도장이 알려 줍니다.
- 주간 스트립은 `bg` 바탕 그대로, 구분선 없이 여백으로 목록과 나눕니다. 칸마다 요일(일 `sun`, 토 `sat`) · 도장 · 날짜 알약입니다. 좌우로 밀면 주가 넘어갑니다.
- 할 일과 루틴은 **같은 모양**입니다. 반복 아이콘은 두지 않습니다(ROUT-05, 요구사항 v1.3).
- 지난 미완료 가져오기 배너는 두지 않습니다. 데스크톱이 v1.2에서 배너를 걷어내고 하루 메뉴로 모은 결정을 그대로 따릅니다(요구사항 F3).
- 할 일 추가는 목표 이름표의 `+`뿐입니다(`MobileAdd` 참고). 하단 바도, 떠 있는 `+`도 없습니다.
- 빈 날에도 안내 문구 없이 활성 목표 이름표의 `+`로 바로 추가합니다.

### 월간 펼침 (`MobileMonth`)

- 상단 줄의 [W | M]에서 M을 고른 상태입니다. W로 돌아가면 주간 스트립이 됩니다.
- 7×6 격자, 칸 높이 64. 칸마다 도장 + 날짜 알약이고, 이번 달이 아닌 날은 투명도 0.4입니다.
- 선택한 날은 먹으로 채운 알약, 오늘은 먹 테두리 알약입니다(데스크톱과 같은 규칙).
- 격자 역시 고정이 아닙니다. 아래 목록과 함께 스크롤되어, 올리면 목록이 넓어집니다.
- 달 이동은 격자를 좌우로 밀어서 합니다. 상단 줄에 `[W | M]`이 들어오면서 이전·다음 달 화살표는 두지 않습니다(M3).

### 할 일 추가 (`MobileAdd`)

데스크톱과 같은 방식입니다. 별도 추가 화면이 아니라 **그 목표 자리에 입력 줄이 열립니다.**

- 목표 이름표의 `+`를 누르면 그 목표의 목록 맨 아래에 입력 줄이 생깁니다. 줄 배경은 `chip`, 왼쪽에 빈 체크 박스 자리, 캐럿은 그 목표 색입니다.
- 키보드가 올라오고, 그 위에 액세서리 줄(높이 48)이 붙습니다. 왼쪽은 날짜 버튼("오늘 · 9월 17일", 누르면 날짜 시트), 오른쪽은 [추가].
- Enter로 추가하면 줄이 비워진 채 그대로 남아 다음 입력을 받습니다. 빈 채로 Enter나 바깥을 누르면 닫힙니다.
- 입력 중 파란 링은 없습니다. 먹색 테두리와 목표 색 캐럿만 씁니다.
- 목표를 잘못 골랐으면 닫고 다른 이름표의 `+`를 누릅니다. 입력 줄 안에서 목표를 바꾸지는 않습니다(데스크톱과 동일).

### 메뉴 시트 (`MobileMenu`)

데스크톱 우클릭 메뉴와 **같은 항목**입니다.

- 머리말: 목표 이름표 + 할 일 제목(한 줄, 넘치면 말줄임).
- 항목: 이름 수정 · 날짜 옮기기("캘린더에서 옮길 날짜를 고릅니다") · 오늘만 건너뛰기("루틴은 그 날짜만 비워 둡니다") · 삭제(`danger`).
- 아래에 테두리만 있는 [취소]를 따로 둡니다.
- 각 줄 56pt, 왼쪽에 20px 글리프.

### 날짜 고르기 시트 (`MobileDatePick`, M3)

세 곳이 **같은 시트 하나**를 씁니다: 줄 밀기 [옮기기], 줄 메뉴 "날짜 옮기기", 추가 시트의 날짜 줄. 하루 메뉴의 "미완료 할 일 다른 날로 옮기기"도 같습니다.

- 머리말에 무엇을 옮기는지 적습니다. 한 개면 할 일 제목, 묶음이면 "미완료 할 일 3개".
- 빠른 선택 줄: [오늘] · [내일] · [다음 주]. 높이 44, 알약, 고른 것 없이 누르면 바로 실행합니다.
- 그 아래 월간 격자. `MobileMonth`의 격자를 **그대로 씁니다**(칸 높이 64, 도장 + 날짜 알약, 이번 달 아닌 날 0.4).
- 날짜를 누르면 **바로 옮기고 닫습니다.** [확인] 버튼을 두지 않습니다(데스크톱 날짜 팝오버와 같은 약속, v1.2 결정).
- 같은 날짜를 고르면 아무 일도 하지 않고 닫습니다. 옮기면 실행 취소 토스트가 뜹니다.

### 하루 메뉴 (`MobileDayMenu`, M3)

데스크톱 `DayMenu`(`components.md`)와 **같은 항목·같은 순서**입니다. 진입점만 다릅니다.

- 진입점은 **상단 줄 오른쪽의 `⋯`**입니다. 배너나 숨은 제스처로 두지 않는다는 2026-10-11 결정은 그대로이고, 날짜 제목 줄을 없애면서 자리만 상단 줄로 옮겼습니다. 지난 날짜·앞날에서도 같은 자리에 있습니다.
- 바텀 시트 항목: 지난 미완료 할 일 N개 가져오기 · 미완료 할 일 다른 날로 옮기기 · (구분선) · 미완료 할 일 전체 삭제(`danger`).
- 쓸 수 없는 항목은 **숨기지 말고 비활성**으로 두고 이유를 보조 설명으로 답니다("오늘 화면에서만 쓸 수 있어요").
- 전체 삭제는 개수를 적은 확인 창을 거칩니다(TODO-12). 세 동작 모두 실행 취소 토스트가 붙습니다.
- 완료한 할 일과 루틴은 세 동작 모두 건드리지 않습니다.
- 각 줄 56pt, 왼쪽 20px 글리프, 아래에 테두리만 있는 [취소] — `MobileMenu`와 같은 모양입니다.

### 제스처 (`MobileGestures`)

규칙을 보여주는 설명 보드입니다. 구현 기준은 이 줄들입니다.

- **왼쪽으로 밀기** → [옮기기](`chip`, 먹 글자) · [삭제](`danger-fill`, 흰 글자). 옮기기는 날짜 고르기 시트로, 삭제는 실행 취소 토스트로 이어집니다(TODO-04, 05).
- **오른쪽으로 밀기** → [완료]. 칸 색은 그 할 일의 `goalTint`, 글자는 `goalInk`입니다. 반대로 밀면 되돌립니다.
- **길게 누르기** 0.4초 → 줄이 살짝 커지고 진동 한 번, 손을 떼면 `MobileMenu`가 올라옵니다.
- 짧게 밀면 라벨만 보이고 손을 떼면 제자리로 돌아옵니다. 끝까지 밀면 바로 실행합니다.

### 삭제 · 실행 취소 (`MobileUndo`)

- 되돌릴 수 있는 동작에는 항상 토스트를 띄웁니다(데스크톱과 같은 약속).
- 토스트는 좌우 16, 아래 safe area + 10, 최소 높이 54, 모서리 999(알약), `ink` 바탕 + `bg` 본문입니다. 오른쪽 [실행 취소]는 시안처럼 파란 `toast-action`(`colors.toastAction`), 14/800으로 표시합니다(2026-10-27 사용자 결정). 라이트는 `#9DB8FF`, 다크는 `#2F5BD8`이며 일반 닫기는 `bg` 글자색입니다.
- 5초 뒤 사라지고, 그 안에 다른 동작을 하면 새 토스트로 바뀝니다.
- 문구는 데스크톱과 같습니다: "'OS 과제 3장 정리'를 지웠어요". 조사는 받침에 따라 을/를을 고릅니다.

### 오프라인 표시 (`MobileOffline`, M5)

데스크톱은 타이틀바 오른쪽에 넣었지만(`screens.md`) 폰에는 타이틀바가 없습니다.

- 상단 줄(월 제목·[오늘]·[W | M]·`⋯`·설정) **아래, 주간 스트립 위**에 가로 전체 띠를 넣습니다. 띠는 상단 줄과 함께 고정이고 스크롤되지 않습니다. 높이 28, `segBg` 배경, 아래 1px `line`, 13px `ink2`, 가운데 정렬.
- 문구는 데스크톱과 같습니다: "오프라인이라 보기만 할 수 있어요"(SYNC-04).
- 띠가 생기면 그만큼 아래 내용이 밀립니다. 주간 스트립이나 목록 위에 겹치지 않습니다.
- 오프라인이면 **쓰기 진입점을 비활성**으로 두고(체크·목표 이름표의 `+`·밀기·메뉴의 쓰기 항목) 이유를 보조 설명으로 답니다. 숨기지 않습니다 — 하루 메뉴와 같은 규칙입니다.
- **실시간 연결 상태와 오프라인은 다른 것입니다.** 실시간 구독이 끊겼다고 이 띠를 띄우거나 쓰기를 막지 않습니다(데스크톱 6단계에서 고친 규칙). 띠의 근거는 기기의 네트워크 상태 하나뿐입니다.
- 저장 실패는 이 띠가 아니라 기존 토스트로 알립니다: "저장하지 못했어요 · 다시 시도"(SYNC-02).

### 목표 관리 (`MobileGoals`)

- 데스크톱의 네 화면(`GoalSheet`/`GoalAdd`/`GoalEdit`/`GoalArchive`) 구조를 그대로 따릅니다.
- 머리글 "목표 N개" + 카드 목록. 줄마다 목표 이름표 · "할 일 42개, 루틴 1개" · `›`. 줄을 누르면 편집으로 들어갑니다.
- 카드 아래 한 줄: "길게 눌러 순서를 바꾸고, 왼쪽으로 밀면 보관할 수 있어요. 활성 목표는 하나 이상 남겨 둡니다."(GOAL-04, GOAL-07)
- 별도 카드로 "보관한 목표  N개  ›".
- 하단 고정 먹색 [목표 추가] → 추가 화면(push).
- 마지막 남은 활성 목표는 밀어도 보관 칸이 나오지 않고, 대신 "활성 목표가 하나는 있어야 해요" 토스트를 띄웁니다.

### 루틴 관리 (`MobileRoutines`)

- 머리글 "돌고 있는 루틴 N개" + 카드. 줄마다 목표 이름표 · 제목 · "매주 월·수·금 · 9월 7일부터" · `›`.
- 카드 아래: "왼쪽으로 밀면 오늘부터 그만두기. 지난 기록은 캘린더에 그대로 남아 있어요."(ROUT-09)
- 아래에 "끝난 루틴 N개" 구역.
- 하단 고정 [루틴 만들기] → `MobileRoutineEdit`.

### 루틴 편집 시트 (`MobileRoutineEdit`)

- 시트 머리말: [취소] · "루틴 만들기" · [저장](굵게).
- 제목 입력 → 목표 이름표 고르기 → 반복 세그먼트(매일 / 매주 / 매월) → 요일 7개 원형(44pt, 고른 것은 먹 채움) → 기간 카드(시작일 · 종료일, 누르면 날짜 시트).
- **다음 5회 미리보기는 두지 않습니다**(v1.3 결정, 데스크톱과 동일).
- 규칙을 바꿔 저장하고 시작일이 오늘보다 이전이면 `MobileRoutineScope`를 먼저 띄웁니다(ROUT-08).

### 루틴 규칙 적용 범위 (`MobileRoutineScope`, M4)

데스크톱 `RoutineScope`(`screens.md`)와 **같은 내용**입니다. 확인 창 대신 바텀 시트입니다.

- 규칙(주기·요일·일·시작일)을 바꿔 저장할 때, 그리고 시작일이 오늘보다 이전일 때만 뜹니다(ROUT-08). 그 외에는 묻지 않고 바로 저장합니다.
- 맨 위에 바뀐 내용 한 줄: `매주 화·목·토 → 매주 월·수·금`.
- 선택지 두 장의 카드. 고른 카드에 `selectionRing`. 기본은 **오늘부터**입니다.
  - **오늘부터** — "어제까지의 규칙과 완료 기록은 그대로 두고, 9월 17일부터 새 규칙으로 보여요."
  - **과거 날짜까지 모두** — "시작일(9월 1일)부터 새 규칙으로 다시 계산해요. 새 규칙에 맞지 않는 날의 완료 기록은 지우지 않고 숨겨요."
- 카드마다 **2주치 미니 캘린더**(이번 주 + 다음 주, 14칸)로 결과를 보여줍니다. 칸은 `DayCell`보다 작게 두되 범례(끝낸 날 · 기록 없음 · 예정)를 답니다. 폭이 모자라면 범례를 두 줄로 내립니다.
- 맨 아래 먹색 버튼의 문구는 고른 쪽을 따릅니다: [오늘부터 적용] / [모두 적용]. 위에 테두리만 있는 [취소].
- 되돌릴 수 없는 동작이므로 실행 취소 토스트를 붙이지 않습니다(`components.md` 확인 창 규칙).

### 루틴 줄 메뉴 (`MobileRoutineMenu`, M4)

할 일 줄의 `MobileMenu`와 같은 모양이고 항목만 다릅니다. 밀기로 되는 일은 여기에도 있습니다(MOB-01).

- 하루 목록의 루틴 줄: **오늘만 건너뛰기**(또는 건너뛰기 취소) · 루틴 편집 · (구분선) · 그만두기(`danger`).
- 루틴 관리 화면의 줄: 루틴 편집 · (구분선) · 그만두기(`danger`).
- **그만두기**는 바로 실행하지 않고 선택지 두 개를 묻습니다(ROUT-09): "오늘부터 그만하기"(어제까지의 기록과 표시는 캘린더에 그대로 남아요) / "완전히 삭제"(모든 날짜에서 사라지고, 완료 기록도 더 이상 보이지 않아요).
- 건너뛰기와 건너뛰기 취소에는 실행 취소 토스트를 붙입니다(ROUT-07).

### 설정 (`MobileSettings`)

- 인셋 그룹 카드 4개. 머리글 13/700 `ink2`, 카드 모서리 12, 줄 사이 1px `line`.
- 계정: 이메일 · 로그아웃("이 기기에 저장된 데이터도 함께 지워져요").
- 보기: 주 시작 요일(일/월) · 테마(자동/라이트/다크) — 데스크톱과 같은 세그먼트.
- 목표와 루틴: 목표 관리 `›` · 루틴 관리 `›`.
- 정보: 버전 · 계정 삭제(`danger` 글자 + "목표, 할 일, 루틴 기록을 모두 지워요"). 확인 창은 개수를 적고 이해 체크를 켜야 버튼이 켜집니다(AUTH-06).
- 단축키 구역은 없습니다.

### 다크 (`MobileTodayDark`)

- 라이트와 같은 구조에 다크 토큰만 바꿔 끼웁니다. 따로 그린 화면이 아닙니다.
- 확인한 값: 본문 16.4:1, 보조 7.0:1, 목표 이름표 글자 4.57~4.84:1, 체크 표시 3.37~6.72:1.
- 다크에서는 카드에 `inset 0 0 0 1px line`을 더해 배경과 구분합니다.

### 첫 실행 안내 (`MobileFirstRun`, M6)

- 첫 로그인 뒤 프로필을 읽어 하루 화면을 열 때 바텀 시트 한 장을 보여 줍니다. 제목 "두 가지만 알아두세요", 오른쪽 [건너뛰기], 아래 먹색 [시작하기].
- 첫 줄은 "할 일 줄을 밀어 보세요"와 오른쪽 완료·왼쪽 옮기기/삭제 설명, 두 번째는 "줄을 길게 눌러 보세요"와 같은 동작을 메뉴로 할 수 있다는 설명입니다. 두 줄 사이 `line`, 안쪽 간격 16, 제목 20, 본문 16/행간 1.5. 기존 `BottomSheet`·버튼·테마·safe area를 씁니다.
- 완료·건너뛰기·배경 탭·아래로 닫기는 모두 기기별 AsyncStorage에 같은 확인 표시를 저장합니다. 로그아웃/계정 전환 후에도 확인 표시는 유지합니다. 저장 실패는 토스트로 알리고 사용을 막지 않습니다.
- 별도 그림이나 새 색은 없습니다. 안내를 건너뛴 뒤에도 줄의 메뉴 버튼·길게 누르기·VoiceOver로 모든 동작을 실행할 수 있습니다(MOB-01).

### 빈 상태 (`MobileEmpty`, M6)

- 성공적으로 읽은 하루 목록의 항목이 0개여도 빈 날 안내 문구는 표시하지 않습니다. 활성 목표 이름표의 `+`는 유지합니다(2026-10-19 사용자 요청).
- 활성 목표도 없으면 "설정에서 목표를 만든 뒤 첫 할 일을 추가해 주세요."와 [설정] 버튼을 보여 주고 목표 관리로 진입할 수 있게 합니다. 추가 바는 비활성입니다. 가입 시 기본 목표가 생기는 AUTH-04 규칙은 유지하며 서버가 0개를 반환하는 상태도 안내합니다.
- 로딩·조회 실패·오프라인 캐시 없음은 빈 상태로 간주하지 않습니다. 각각 준비 안내·다시 시도·연결 안내를 보여 줍니다.
