# docs/design

Nodii의 화면 기준입니다. UI 코드를 쓰기 전에 `DESIGN.md` → 이 폴더 순서로 읽습니다.

| 파일 | 내용 |
| --- | --- |
| `../../DESIGN.md` | 왜 이렇게 생겼는지, 원칙과 금지 사항, 목표 색 계산 규칙 |
| `tokens.md` | 색·글꼴·간격·모션 값, Tailwind v4 설정과 글꼴 번들 방법 |
| `components.md` | 체크, 목표 이름표, 캘린더 칸, 컨텍스트 메뉴, 토스트, 확인 창, 버튼, v3 소셜 컴포넌트(`GoalMark`·`Avatar`·`FollowButton`·탭바 등) |
| `screens.md` | 화면별 구조와 문구, 요구사항 ID 연결 |
| `mobile-screens.md` | 모바일(iOS) 화면 스펙 — 데스크톱에서 그대로 가져오는 것과 바꾸는 것, v3 소셜 화면(§2-1) |

## 시안

화면 시안은 Claude 디자인 캔버스 "Nodii 디자인"에 아트보드로 있습니다. 기본 페이지 둘(v3 반영)과 v3 소셜 페이지들이 있습니다.

- **데스크톱**: 메인 라이트·다크(v3: 아바타 줄·탭바), 로그인, 루틴 편집, 목표 관리·추가·편집(v3: 공개 범위)·보관함, 설정(v3: 프로필 탭 오른쪽 화면), 루틴 관리, 루틴 규칙 적용 범위, 업데이트 필요 안내, 스타일 기초(v3 소셜 토큰 포함), 알림·사람 하루(v3).
- **모바일 (iOS)**: 로그인, 오늘(v3), 월간 펼침, 할 일 추가 시트, 메뉴 시트, 제스처, 삭제·실행 취소, 목표 관리, 루틴 관리, 루틴 편집 시트, 설정(v3), 오늘·다크.
- **v3 소셜 페이지**: "소셜 (v3)"(공개 범위 표시·친구 보기·오늘에 보일 사람), "목표 공개 범위", "데스크톱 소셜", "기본 프로필 이미지", "알림 · 사람 하루 · 사진 자르기", "프로필 탭 · 설정". 각 페이지에는 시안 여러 개와 최종안이 같이 있습니다. **최종안은 `docs/16-v3-social-plan.md`의 결정(D16~D30)에 적힌 아트보드 이름**이고, 나머지는 비교용입니다.

시안과 이 문서가 다르면 **이 문서가 기준**입니다. 시안을 고쳐야 하면 사람에게 알려 주세요.

## 코딩 에이전트가 지킬 것

1. 색·크기·모서리 값을 새로 만들지 말고 `tokens.md`의 토큰을 씁니다. 필요한 토큰이 없으면 만들지 말고 보고합니다.
2. 목표 색이 들어가는 곳은 반드시 `goalInk`·`checkColor`·`stampFill`(`@nodii/core`)을 거칩니다(v2). HEX를 직접 글자색으로 쓰지 않습니다.
3. 새 컴포넌트에는 기본·호버·포커스·비활성 상태를 모두 만듭니다. `outline: none`만 남기는 코드는 금지입니다.
4. 되돌릴 수 있는 동작에는 실행 취소 토스트를, 되돌릴 수 없는 동작에는 개수를 알려주는 확인 창을 붙입니다.
5. 문구는 짧고 친근한 존댓말로 쓰고, `screens.md`에 있는 문구를 그대로 씁니다.
