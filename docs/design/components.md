# 컴포넌트 스펙

> 토큰 이름은 `docs/design/tokens.md` 기준. 모든 컴포넌트는 기본·호버·포커스·비활성 상태를 갖춥니다.

## 체크 (`TodoRow`, `RoutineRow`)

22×22, 반지름 7.

| 상태 | 모양 |
| --- | --- |
| 미완료 | 안쪽 `box`, 테두리 1.5px `field` |
| 완료 | 안쪽 목표 색, 체크 표시는 `checkColor(goalColor)` |
| 건너뜀(루틴) | 안쪽 `box`, 테두리 1.5px `line-2`, 가운데 짧은 가로선 |
| 누르는 중 | `scale(0.86)` |

- 제목은 15px. 완료·건너뜀이면 `muted` + 취소선(1px, `line-2`).
- 루틴은 제목 뒤에 반복 아이콘(14px, `muted`)을 붙입니다(ROUT-05).
- 건너뛴 루틴은 아이콘 뒤에 "건너뜀" 12px `muted` 글자를 붙입니다.
- 줄 오른쪽 끝의 `⋯` 버튼은 평소 투명, 호버·포커스 때 나타납니다. 줄 어디서든 우클릭해도 같은 메뉴가 열립니다.

## 목표 이름표 (`GoalChip`)

- 높이 32, 반지름 999, 좌우 여백 14/11, 바탕 `goalTint`, 글자 `goalInk`, 굵기 700.
- 하루 목록에서는 이름표 **자체가 추가 버튼**입니다. 이름 뒤에 14px `+` 아이콘을 넣고, 누르면 그 목표의 입력 줄이 열립니다(TODO-01).
- 보관한 목표의 이름표는 같은 모양에 불투명도 55%.

## 할 일 입력 줄

- 체크 자리에 빈 체크 모양(테두리 `line-2`)을 두고, 그 옆에 입력칸, 오른쪽 끝에 "Enter로 추가, Esc로 닫기" 12px `muted`.
- 줄 바탕은 `side`. 캐럿 색은 목표 색.
- Enter로 추가한 뒤에도 입력 줄은 열려 있습니다(연속 입력). IME 조합 중 Enter는 무시합니다(`isComposing`).

## 캘린더 칸

한 칸 = 도장(위) + 날짜 숫자(아래), 높이 58, 반지름 12.

| 상황 | 도장 |
| --- | --- |
| 항목 없음 | 없음(자리만 24px) |
| 지난날·오늘에 남음 | `stamp` 바탕, 남은 개수 12/700 |
| 앞날에 예정 | 테두리 1.5px `line-2`, 남은 개수 `muted` |
| 모두 끝냄 | `ink` 바탕, 흰 체크 |

- 숫자: 선택한 날은 `ink` 알약에 흰 글자, 오늘(선택 안 됨)은 1.5px `ink` 테두리 알약, 나머지는 평소 색(일·토는 `sun`/`sat`), 다른 달은 불투명도 40%.
- 남은 개수 = 그날의 할 일 + 루틴 중 미완료(건너뛴 루틴 제외) — CAL-02.

## 컨텍스트 메뉴

- 너비 220, 반지름 12, `surface` 바탕, 메뉴 그림자. 항목 높이 34.
- 할 일: 수정 · 내일로 · 오늘로(오늘이 아닐 때만) · 날짜 선택 · (구분선) · 삭제(`danger`).
- 루틴: 이날은 건너뛰기(또는 건너뛰기 취소) · 루틴 편집.
- 오른쪽에 12px `muted`로 결과를 미리 보여줍니다(예: "내일로 → 9월 18일").
- "날짜 선택"을 고르면 메뉴가 닫히고 **왼쪽 캘린더가 고르기 모드**로 바뀝니다: 상단에 "옮길 날짜를 고르세요 / 취소" 띠, 칸 호버는 파란 톤.
- 화면 아래쪽에서 열리면 위로 뒤집습니다. Esc, 바깥 클릭, 스크롤로 닫힙니다.

## 토스트 (실행 취소)

- 하루 목록 가운데 아래, 높이 44, 반지름 12, `ink` 바탕에 `bg` 글자, 5초 뒤 사라짐.
- 문구 + "실행 취소" 버튼. 옮기기·삭제·가져오기·건너뛰기·루틴 종료에 붙입니다(TODO-04, TODO-05, TODO-10, ROUT-07, ROUT-09).
- 저장 실패 토스트는 같은 모양에 "저장하지 못했어요"와 "다시 시도" 버튼(SYNC-02).

## 확인 창

- `role="alertdialog"`, 너비 420~440, 반지름 16, 스크림 위. Esc로 닫히고 기본 포커스는 **취소**.
- 되돌릴 수 없는 동작만 씁니다: 목표 삭제(GOAL-06), 계정 삭제(AUTH-06), 루틴 종료·삭제(ROUT-09), 루틴 규칙 적용 범위(ROUT-08).
- 본문에 **함께 사라지는 것의 개수**를 적고, 가능하면 덜 위험한 대안 버튼을 같이 둡니다("대신 보관하기").
- 계정 삭제만 "되돌릴 수 없다는 걸 이해했어요" 체크를 켜야 버튼이 활성화됩니다.

## 버튼

| 종류 | 모양 |
| --- | --- |
| 주요 | `ink` 바탕, `bg` 글자, 굵기 700 |
| 보조 | 투명, 1px `field` 링 |
| 조용한 | 투명, 호버 때만 바탕 5% |
| 위험 | `danger` 글자(확인 창에서는 `danger` 바탕 + 흰 글자) |
| 비활성 | `box` 바탕 + `muted` 글자, 불투명도로 처리하지 않음 |

높이는 창 안 30~34, 모달 38~40, 로그인 48.

## 세그먼트 (주 시작 요일, 테마, 반복 종류)

- 바탕 `box`, 안쪽 버튼 높이 30~34, 선택된 것만 `surface` + 얇은 그림자.
- `role="radiogroup"` + `role="radio"` + `aria-checked`.
