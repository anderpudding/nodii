# 화면 스펙

> 요구사항 ID는 `docs/01-requirements.md`, 화면 구조는 `docs/02-system-design.md` §7 기준.
> 각 화면 이름 옆의 괄호는 디자인 캔버스의 아트보드 이름입니다. v3 소셜로 바뀐 화면에는 "v3"를 붙였고, 새 화면은 맨 아래 "v3 소셜 화면"에 있습니다(근거 `docs/16-v3-social-plan.md`).

## 메인 (`Main`, `MainDark`) — 1120×740 · v3

> v3에서 바뀐 화면입니다(D21·D22·D30, 시안 `Main`·`MainDark`·`DeskSocialFinal`). 소셜이 꺼져 있으면(`social_enabled = false`) 아바타 줄과 탭바 없이 같은 배치를 씁니다.

```
┌ ● ● ● ─────────────────────────────────────────────────────┐
│ (나) (민수) (지은) (현우) (서연) (≡ 목록)        아바타 줄 46 │
├ 사이드바 380 ──────────┬ 하루 목록 ──────────────────────────┤
│ 2026년 9월   ◀ ▶       │                    [오프라인] [슬라이더] │
│ 일 월 화 수 목 금 토   │ (●공부 +)                            │
│ [도장/날짜 6줄]        │  ☑ 알고리즘 2문제               ⋯    │
│ 목표 관리 / 루틴 관리  │                                      │
├────────────────────────┴──────────────────────────────────────┤
│                   [오늘]  [알림]  [프로필]          탭바 56    │
└───────────────────────────────────────────────────────────────┘
```

- 창 맨 위 신호등 줄 아래에 **전체 폭 아바타 줄**(SOC-35). 사람을 고르면 사이드바 캘린더와 하루 목록이 그 사람 것(읽기 전용, SOC-32)으로 바뀌고 고른 날짜는 그대로입니다(SOC-33). ≡ 목록은 "오늘에 보일 사람"을 오른쪽 하루 목록 자리에 엽니다(`DeskSocialFinalManage`).
- 사이드바 월 제목은 누르면 오늘로 가는 버튼입니다. `[오늘]` 버튼은 없앴습니다(D30). `◀ ▶`는 달 이동 그대로.
- 하루 목록 위에는 **날짜 제목·"N개 중 M개 끝냄" 요약·날짜 화살표·설정 글리프가 없습니다**(D21). 오른쪽 끝에 하루 메뉴 버튼(슬라이더 아이콘, 원 36)만 있고, 친구를 볼 때는 숨깁니다. 오프라인 표시는 그 왼쪽에 둡니다(SYNC-04).
- 날짜 이동은 캘린더 클릭과 `←/→`, `⌘T`는 오늘(SET-03 그대로).
- 하루 메뉴 항목은 v2와 같습니다(가져오기·다른 날로 옮기기·미완료 전체 삭제, TODO-10~12). 가져오기는 오늘을 보고 있을 때만.
- 아바타 줄·사이드바·탭바는 고정이고 **목표별 목록만 스크롤**합니다. 스크롤바는 보이지 않습니다.
- 창이 좁으면(폭 760 미만) 사이드바를 접고 하루 목록 위에 주간 스트립을 둡니다(CAL-07). 아바타 줄과 탭바는 그대로. 최소 크기 400×600.
- 목표 이름표는 `GoalMark` + 이름 + `+`. `+`는 할 일 추가 전용이고 루틴 추가는 루틴 관리에서만 합니다.
- 할 일과 루틴은 목록에서 **같은 모양**입니다(ROUT-05).
- 실행 취소 토스트는 탭바 위에 뜹니다.
- 사이드바 아래 메뉴: 목표 관리 → `GoalSheet`, 루틴 관리 → `RoutineList`. 설정은 프로필 탭으로 옮겼습니다(아래 `Settings`).

## 로그인 (`Login`) — 880×600

- 1단계: 이메일 입력 + “코드 받기”. 사용자 결정(2026-10-27)에 따라 모바일과 같은 제목 **“Nodii 시작하기”**, 설명 **“이메일로 받은 6자리 코드로 로그인해요. 처음이면 가입도 함께 돼요.”**를 씁니다.
- 일반 이메일 단계의 버튼 아래 32px에 `muted` 도움말(13/500)을 둡니다: **“코드는 10분 동안 쓸 수 있어요. 메일이 안 보이면 스팸함도 확인해 주세요.”** 코드 입력·심사 계정 비밀번호 단계에서는 이 도움말을 숨깁니다. 빈 이메일의 버튼 비활성·유효성 검사·인증 흐름은 유지합니다.
- 2단계는 사용자 결정(2026-10-27)에 따라 `desktop-designs/로그인 (이메일 코드).png`의 문구·배치를 따릅니다. 제목은 **“코드를 보냈어요”**, 설명은 **“{email}으로 보낸 6자리 코드를 입력해 주세요. 메일이 안 보이면 스팸함도 확인해 주세요.”**입니다. 이메일은 `ink` 700, 나머지 설명은 `ink-2` 15/400으로 자연스럽게 줄바꿈합니다.
- 싹이 브랜드 → 제목(28/800)·설명 → 6칸 코드 → 가로 전체 “로그인” → 하단 보조 동작 순서입니다. 별도 Nodii 글자와 보이는 “인증 코드” 라벨은 빼되 입력의 접근성 이름·연결된 라벨은 유지합니다. 브랜드와 제목은 24px, 제목과 설명은 12px 간격입니다.
- 로그인 패널은 기존 최대 너비 380px, 창 좌우 여백 48px를 유지합니다. 위 여백 72px(48+24)·아래 48px 안에서 가운데에 배치하고, 작은 창·긴 이메일에서도 가로로 넘치지 않게 축소/줄바꿈합니다. 높이가 부족하면 페이지를 스크롤합니다. 이 배치는 로그인에만 적용하며 업데이트 안내 화면은 유지합니다.
- 코드 칸은 8px 간격으로 같은 너비를 나눠 쓰고, 넓을 때 정사각형·좁을 때 최소 높이 48px를 유지합니다. 입력·코드 모서리는 기존 14px, 주요 버튼은 높이 48px 알약입니다.
- 하단 **왼쪽은 “다른 이메일로”**, **오른쪽은 재전송**입니다. 60초 대기 중에는 **“1:00 뒤에 다시 받을 수 있어요”**처럼 `분:초` 안내만 보이고, 0초가 되면 **“코드 다시 받기”** 버튼이 나타납니다(AUTH-07). 안내는 매초 읽어 주지 않습니다. 좁으면 보조 동작은 줄바꿈하며, 키보드 포커스 링은 유지합니다.
- 오류 문구는 `role="alert"`로: 틀린 코드 → "코드가 맞지 않아요. 메일의 숫자를 다시 확인해 주세요.", 만료 → "코드 유효 시간(10분)이 지났어요. 새 코드를 받아 주세요."
- 6칸이 다 차기 전에는 로그인 버튼이 비활성입니다.
- 심사용 데모 계정(AUTH-08)의 비밀번호 입력칸은 해당 이메일일 때만 나타납니다. 일반 사용자에게는 보이지 않습니다.

## 목표 관리 (`GoalSheet`) — 시트, 창 위에서 내려옴

> v1.3 결정: 목록·추가·편집·보관함을 **네 화면으로 나눕니다.** 한 시트에서 펼쳐 고치던 방식은 없앴습니다.

- 목록만 보여줍니다. 줄: 드래그 손잡이 · 목표 이름표 · "할 일 42개, 루틴 1개" · (호버 때) [편집] [보관].
- 머리말 오른쪽: [+ 추가하기](→ `GoalAdd`) · [완료]. 목록 위 한 줄: "목표 N개 · 드래그해서 순서를 바꿀 수 있어요".
- [편집] → `GoalEdit`. 줄 자체를 눌러도 편집으로 들어갑니다.
- 마지막 남은 활성 목표는 보관 버튼이 비활성이고 `title`로 이유를 알려줍니다(GOAL-07).
- 목록 맨 아래: "보관한 목표  N개  ›" 줄 → `GoalArchive`.

## 목표 추가 (`GoalAdd`) — 새 창

- 이름(자동 포커스, 1~50자, 예시 placeholder "예: 공부") · 프리셋 11색 + 무지개(직접 고르기, SOC-27) · **공개 범위 세그먼트**(v3, SOC-25. 처음 값은 설정의 "새 목표의 기본 공개 범위", SOC-28).
- v3 시안: `GoalAdd`(`GoalVisMac` 바탕). HEX 입력은 무지개 버튼으로 펼치는 선택기 안으로 들어갔습니다.
- HEX 형식이 틀리면 테두리 `danger` + "#RRGGBB 형식으로 입력해 주세요", 이름이 비었거나 HEX가 틀리면 [추가]가 비활성입니다.
- [취소]와 닫기(X)는 목표 관리로 돌아갑니다.

## 목표 편집 (`GoalEdit`) — 새 창

- 추가와 같은 폼에 값이 채워져 있습니다. v3 순서: 이름 · 색상(프리셋 + 무지개, 선택기는 색상 줄 아래로 펼침) · **공개 범위** · 보관/삭제(SOC-25·27, 시안 `GoalEdit` = `GoalVisMac`). 모달 [저장]으로 확정합니다.
- 아래 구역에 두 가지를 따로 둡니다.
  - 보관하기: "새 할 일 목록에서 숨기고, 지난 기록은 그대로 남겨요" + [보관]
  - 목표 삭제: "할 일 42개와 루틴 1개가 함께 사라져요" + [삭제](`danger`)
- 삭제 확인 창: "'공부' 목표를 삭제할까요?" + "할 일 42개와 루틴 1개가 모든 날짜에서 함께 삭제돼요. 지난 기록을 남기려면 보관을 써 주세요." + [대신 보관하기] [취소] [삭제](GOAL-06).
- 마지막 남은 활성 목표는 보관·삭제가 비활성입니다(GOAL-07).

## 보관한 목표 (`GoalArchive`) — 시트

- 들어오는 길 두 개: 목표 관리 맨 아래 줄, 설정의 "목표 › 보관한 목표".
- 머리말: [‹ 목표 관리] · 제목 · [완료]. 그 아래 안내 한 줄: "보관한 목표는 새 할 일 목록에 나오지 않아요. 지난 날짜의 할 일과 기록은 캘린더에 그대로 남아 있어요."
- 줄: 이름표 · "할 일 11개 · 9월 12일에 보관" · [보관 해제]. 해제하면 실행 취소 토스트가 뜹니다.
- 비었을 때: "보관한 목표가 없어요. 목표 관리에서 보관하면 여기로 모여요."

## 루틴 편집 (`RoutineEditor`) — 모달

- 제목 · 목표(이름표 중 고르기) · 반복(매일/매주/매월 세그먼트) · 간격 스테퍼 · 요일 또는 날짜 고르기 · 시작일/종료일.
- v1.3 결정: **"다음 5회 미리보기"는 없앴습니다.**
- 매월에서 없는 날짜는 말일에 나타난다는 안내를 붙입니다(ROUT-04).
- 요일이나 날짜를 하나도 고르지 않으면 고르는 자리 바로 아래에 `danger` 색 안내("요일을 하나 이상 골라 주세요" / "날짜를 하나 이상 골라 주세요")가 뜨고 저장이 비활성입니다.

## 루틴 규칙 적용 범위 (`RoutineScope`) — 확인 창

- 규칙(주기·요일·일·시작일)을 바꿔 저장할 때만, 그리고 시작일이 오늘보다 이전일 때만 뜹니다(ROUT-08).
- 맨 위에 바뀐 내용: `매주 화·목·토 → 매주 월·수·금`.
- 선택지 두 개, 각각 아래에 **2주치 미니 캘린더**로 결과를 보여줍니다(끝낸 날/기록 없음/예정 범례 포함).
  - 오늘부터(기본): "어제까지의 규칙과 완료 기록은 그대로 두고, 9월 17일부터 새 규칙으로 보여요."
  - 과거 날짜까지 모두: "시작일(9월 1일)부터 새 규칙으로 다시 계산해요. 새 규칙에 맞지 않는 날의 완료 기록은 지우지 않고 숨겨요."
- 확인 버튼 문구는 고른 선택지에 따라 "오늘부터 적용" / "모두 적용".

## 루틴 관리 (`RoutineList`) — 시트

- 목표별로 묶고 줄마다 제목과 "매주 화·목·토, 9월 1일부터". 호버 때 [편집] [그만두기].
- [그만두기] → 확인 창에서 둘 중 하나(ROUT-09):
  - 오늘부터 그만하기: "어제까지의 기록과 표시는 캘린더에 그대로 남아요."
  - 완전히 삭제: "모든 날짜에서 사라지고, 완료 기록도 더 이상 보이지 않아요."
- 아래에 "끝난 루틴" 구역: 기간과 "기록은 캘린더에 남아 있어요".
- 오른쪽 위 [새 루틴] → `RoutineEditor`.

## 설정 (`Settings`) — 프로필 탭의 오른쪽 하위 화면 · v3

> v3(D28): 설정은 시트가 아니라 **프로필 탭 오른쪽 칸**에 "‹ 팔로잉" + 큰 제목 "설정"으로 열립니다. 톱니 버튼과 `⌘,`로 엽니다. 두 단으로 놓습니다. 소셜이 꺼져 있으면 v2처럼 시트로 엽니다.

- 계정: 이메일, 핸들(`@sungjun`, "30일에 한 번 바꿀 수 있어요", SOC-02), 로그아웃(캐시도 지운다는 안내).
- 알림(v3): 친구 완료 알림 `›`(기본 꺼짐, 전체 + 사람별 하위 화면, D10·SOC-51) · 새 팔로워(스위치) · 받은 좋아요(스위치)(SOC-53).
- 개인정보(v3): 새 목표의 기본 공개 범위 `›`(나만, SOC-28) · ID로 검색 허용(스위치, "끄면 링크로만 나를 찾을 수 있어요", SOC-06) · 차단한 사람 `›`(SOC-61).
- 보기: 주 시작 요일(일/월), 테마(시스템/라이트/다크).
- 목표와 단축키: "보관한 목표 N개 ›" → `GoalArchive` · "키보드 단축키 ›"(`⌘N` 새 할 일 · `⌘T` 오늘로 · `←/→` 이전·다음 날 · `⌘,` 설정 · `⌘1~3` 탭, SET-03).
- 정보: 버전 · 개인정보처리방침·이용약관 · 계정 삭제(`danger`, "목표, 할 일, 루틴, 팔로우 기록을 모두 지워요"). 확인 창은 지워질 개수를 적고, 이해 체크를 켜야 삭제 버튼이 켜집니다(AUTH-06, SOC-70).

## 업데이트 필요 안내 (`UpdateRequired`) — 전체 화면

- 로그인 전에 뜨고 앱을 막습니다(SET-05, §6.7).
- "새 버전이 필요해요" + 데이터는 그대로라는 안내 + [App Store에서 업데이트] + 지금 버전 / 필요한 버전.
- 버전을 읽지 못하면(오프라인 등) 이 화면을 띄우지 않고 그냥 진행합니다.

## v3 소셜 화면 (macOS)

시안은 디자인 캔버스의 "알림 · 사람 하루 · 사진 자르기", "프로필 탭 · 설정", "데스크톱 소셜", "목표 공개 범위" 페이지에 있습니다. 공통 컴포넌트는 `components.md`의 "v3 소셜" 절, 값은 `tokens.md` §9.
