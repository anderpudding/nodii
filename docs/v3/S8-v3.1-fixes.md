## 2. 두 앱 공통

### 2.1 캘린더는 이번 달 날짜만 (피드백 4·14)

- **월 캘린더**(macOS `features/calendar/CalendarGrid.tsx` · `MonthCalendar.tsx`, iOS `features/today/MonthGrid.tsx` · `DayCell.tsx`)에서 이번 달이 아닌 칸은 **그리지 않습니다.** 지금은 흐리게(`calendar-outside`, `outside ? 0.4`) 보입니다.
  - 칸 자리는 남겨 요일 열이 맞게 합니다(빈 칸). 빈 칸은 누를 수 없고, 스크린 리더에도 읽히지 않습니다(`aria-hidden` / `accessibilityElementsHidden`·`importantForAccessibility="no-hide-descendants"`).
  - 이번 달 날짜가 하나도 없는 줄(맨 아래 6번째 줄 등)은 **줄째 빼서** 캘린더 높이가 그 달의 주 수만큼만 되게 합니다. 달마다 높이가 4~6줄로 바뀌는 것은 의도입니다.
  - 같은 규칙을 친구 하루(`FriendDay`)·사람 하루 페이지의 캘린더에도 적용합니다(같은 컴포넌트면 자동).
- **주간 보기**(iOS W, macOS 좁은 창의 주간 보기)는 그대로 둡니다. 한 주가 두 달에 걸치면 7일을 모두 보여 줍니다.
- 날짜 옮기기 캘린더(시트/선택 모드)도 월 캘린더와 같은 규칙입니다.
- 테스트: 다른 달 날짜가 렌더되지 않음, 마지막 빈 줄이 없음(예: 2026년 9월 = 5줄, 2026년 2월 = 4줄이 아님을 확인할 수 있는 달 하나), 다른 달로 넘어가는 이동은 기존 달 이동 버튼으로만.

### 2.2 입력칸 둘레 강조 제거 (피드백 8·15)

- 글자를 쓰는 칸(이메일, 인증 코드 칸, 닉네임, ID, 소개, 친구 찾기 검색, 목표 이름, 루틴 제목, 할 일 제목)에 **포커스되어도 테두리·바깥 링·inset 그림자를 그리지 않습니다.** 커서(caret)만 보입니다.
  - macOS: `index.css`의 `.input:focus { box-shadow… }`, `social.css`의 `.social-input:focus-within { box-shadow… }`, 그리고 전역 `:focus-visible` outline이 `input`·`textarea`·`[contenteditable]`에 걸리지 않게 합니다. **버튼·링크·체크 상자의 키보드 포커스 링(먹색 outline)은 그대로** 둡니다.
  - iOS: 포커스 상태에서 바뀌는 `borderWidth`/`borderColor`/그림자를 뺍니다. 로그인 인증 코드 칸의 "지금 입력할 칸" 테두리도 뺍니다(커서만).
- 오류 상태(빨간 테두리·빨간 바탕, 예: 코드가 틀렸을 때)는 그대로 둡니다. 강조가 아니라 오류 표시입니다.
- 테스트: 포커스 스타일을 검사하던 테스트가 있으면 갱신합니다.

### 2.3 할 일 추가·고치기 칸에 목표 색 밑줄 (피드백 9·16)

- 오늘 화면에서 목표 이름표의 +로 여는 **할 일 추가 칸**(macOS 목록의 입력 줄, iOS `features/today/InlineAdd.tsx`)과 **할 일 제목 고치기 칸**:
  - 회색 상자 바탕을 없애고, 입력칸 아래에 **그 목표 색의 밑줄 2px**을 둡니다. 커서 색도 같은 색입니다.
  - 색은 목표의 **이름표 글자색(`goalInk`)** 을 씁니다. 시안은 목표 색 그대로 그렸지만, 노랑·연두 같은 밝은 프리셋에서 흰 바탕 대비 3:1(비텍스트 대비)을 넘기려면 `goalInk`가 맞습니다. 다크 모드도 `goalInk` 다크 값.
  - 밑줄은 입력칸 폭만큼(체크 상자 오른쪽부터 끝까지). 높이·글자 크기·줄 간격은 기존 할 일 줄과 같게 해서 입력 줄과 저장된 줄의 높이가 바뀌지 않게 합니다.
  - macOS의 "Enter로 추가, Esc로 닫기" 보조 문구는 그대로 둡니다.
- 테스트: 입력칸이 그 목표의 색 값을 받는지(스타일 prop 또는 class) 한 개.

### 2.4 설정 › ID의 "30일에 한 번 바꿀 수 있어요" 제거 (피드백 6·12)

- macOS `features/settings/SettingsSheet.tsx`(약 231행), iOS `features/settings/Settings.tsx`(약 114행)에서 `settings.account.handleHelp` 보조 줄을 뺍니다. ID 줄은 "ID ……… @handle ›" 한 줄입니다.
- `packages/i18n`의 ko·en 카탈로그에서 `settings.account.handleHelp` 키를 지우고 카탈로그 테스트를 맞춥니다.
- **ID 고치기 화면 안의 안내**(`social.handle.changeNotice` 류: "바꾸면 30일 동안 다시 바꿀 수 없어요…")와 쿨다운 안내(`social.handle.cooldown`)는 **그대로** 둡니다. 30일 규칙 자체도 바뀌지 않습니다.

## 3. macOS

### 3.1 "링크를 복사했어요" 토스트를 창 가운데로 (피드백 1)

- 프로필 탭의 [초대 링크 복사](`features/social/SocialShell.tsx` 약 309행)로 뜨는 토스트가 왼쪽으로 치우칩니다. **창 전체의 가로 가운데**, 탭바 위에 뜨게 합니다(시안: 아래에서 76px, 탭바 56px + 여백 20px).
- 프로필 칸이 가운데일 때(D32 기본)와 왼쪽 380 칸으로 미끄러진 뒤 모두 창 가운데입니다.
- 원인을 먼저 찾습니다(예: `[data-sonner-toaster]`의 위치·폭, 토스트 폭 계산, 프로필 칸 레이아웃 안에 갇힌 컨테이너). 다른 토스트(오늘 화면 실행 취소 등)의 위치가 함께 바뀌면 보고에 적습니다.

### 3.2 창 제어 버튼 영역 아래 선 제거 (피드백 2)

- 창 위(신호등 버튼이 있는 영역)와 본문 사이의 가로선을 없앱니다. 시안에는 어느 탭에도 이 선이 없습니다(오늘·알림·프로필·설정·사람 하루 PNG 확인).
- 남기는 선: 아래 **탭바 위 선**(`social-tabbar`의 `border-top`)과 시안에 있는 내용 안의 구분선(예: 프로필 칸 오른쪽 세로선, 사람 하루 머리 아래 선). 어느 선을 지웠는지 보고에 파일·선택자로 적습니다.

### 3.3 프로필 탭 오른쪽 위 사람+ · 톱니 버튼 크기 (피드백 3)

- 시안 `macOS 프로필 탭 (기본 …)`, `M1 · …` 세 장 기준: **36×36 원**, 테두리 1px(`line` 토큰, 시안 #E6E8EC), 아이콘 **18px · 선 굵기 2**, 두 버튼 사이 8px. 그 화면이 열려 있으면(친구 찾기·설정) 테두리 대신 `chip` 바탕(#F2F3F6).
- 위치: 신호등과 같은 줄(높이 52)의 오른쪽 끝, 오른쪽 여백 16px. 프로필 칸이 왼쪽으로 미끄러진 상태에서는 왼쪽 380 칸의 오른쪽 위.
- `aria-label`·툴팁("친구 찾기", "설정 (⌘,)")은 그대로.

### 3.4 오늘 탭 달 이동 버튼 (피드백 5)

- 시안 `메인 · 라이트 (v3)`: 달 제목 오른쪽의 [‹][›]는 **32×32 원**, 테두리 1px(`line2` 토큰), 셰브론 16px · 선 2.2, 버튼 사이 2px. 누를 때·호버 때 바탕만 살짝(기존 `nd-hover` 규칙). 다크도 같은 모양에 다크 토큰.
- 지금 앱의 모양(크기·테두리·아이콘)이 무엇이 다른지 PNG와 나란히 보고 고칩니다. 달 제목을 누르면 오늘로 가는 동작은 그대로.

### 3.5 프로필 사진 자르기 크기·배치 (피드백 7)

- 시안 `macOS 사진 자르기 (모달 520)`과 맞춥니다: **폭 520 모달**, 위 제목, 가운데 정사각 자르기 영역과 원형 마스크, 아래 확대 슬라이더, **[취소][완료]는 아래 오른쪽**. 크기·여백·글자 크기를 PNG에서 재서 맞추고, 재 값을 보고에 적습니다.
- 자르기 동작(끌기·확대·결과 512px·EXIF 제거)은 바꾸지 않습니다(`features/social/AvatarCrop.tsx`).

## 4. iOS

### 4.1 오늘 탭 위쪽: 가운데 "Nodii" + 큰 아바타 (피드백 10)

- 상태 표시줄(안전 영역) 바로 아래에 **높이 44의 머리 줄, 가운데 "Nodii"**(20pt, 800, `ink`)를 둡니다. 앱 이름이라 번역하지 않습니다. 접근성: 머리글(`accessibilityRole="header"`).
- 그 아래 아바타 줄(`features/social/AvatarRow.tsx`)을 키웁니다:
  - 아바타 **64pt**(지금 52), 칸 폭 74, 칸 사이 10, 이름 13pt. 고른 사람의 링(바탕 2.5 + 먹색 2)은 같은 비율로 유지.
  - 기본 이미지(싹이) 아이콘 40pt, 이니셜 22pt, "목록" 버튼의 아이콘 24pt.
  - 줄은 **가로로 밀어 넘깁니다**(스크롤 표시 없음). 화면에 다 안 들어가도 "목록" 버튼이 잘리지 않고 밀어서 닿을 수 있어야 합니다.
  - 줄 위아래 여백: 위 2, 아래 12.
- 내 하루를 볼 때와 친구 하루를 볼 때 머리 줄·아바타 줄은 같습니다. 다크 모드도 같은 크기(D23 다크 색).
- 오늘 탭에서만 바뀝니다. 알림·프로필 탭 머리는 그대로.

### 4.2 친구 하루를 볼 때 아바타 줄과 캘린더 사이 빈 공간 (피드백 11, 버그)

- 아바타 줄에서 친구를 고르면 아바타 줄과 캘린더(날짜 줄) 사이에 알 수 없는 빈 공간이 생깁니다. 시안 `A1 · 이름 달린 아바타 줄`처럼 **내 하루와 같은 간격**이어야 합니다.
- 먼저 원인을 찾아 보고에 적습니다(예: `FriendDay.tsx`가 내 하루에 없는 머리·여백·빈 배너를 그림, 숨긴 하루 메뉴 자리를 비워 둠, 안전 영역 여백이 두 번 들어감, 로딩용 자리 표시가 남음). 증상만 덮는 음수 여백은 쓰지 않습니다.
- 테스트: 친구 하루와 내 하루에서 아바타 줄 아래 첫 요소(월 제목 줄)가 같은 위치(또는 같은 여백 스타일)인지 한 개.

### 4.3 설정 › 새 목표의 기본 공개 범위 줄 (피드백 13)

- 지금은 값 "나만 ›"이 이름 아래로 내려가 상자 높이가 어긋납니다. **이름 왼쪽 한 줄, "나만 ›" 오른쪽**으로 둡니다. 같은 설정 화면의 **"친구 완료 알림 … 끔 ›"** 줄과 같은 컴포넌트·배치를 씁니다.
- 이름은 한 줄(`numberOfLines={1}`), 공간이 모자라면 이름이 줄어들고(`flexShrink`) 값은 줄어들지 않습니다. 큰 글자(접근성 크기)에서는 기존 설정 줄의 큰 글자 규칙을 따릅니다(이름이 두 줄이 되더라도 값은 오른쪽에 세로 가운데).
- "NEW" 표시가 있으면 이름 옆에 그대로.
