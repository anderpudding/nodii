# 컴포넌트 스펙

> 디자인 시스템 v2 (2026-10-27), v3 소셜 컴포넌트 추가(2026-11-11, 아래 "v3 소셜" 절). 토큰 이름은 `docs/design/tokens.md` 기준. 모든 컴포넌트는 기본·호버·포커스(데스크톱)·비활성 상태를 갖춥니다.

## 체크 (`TodoRow`, `RoutineRow`)

모양은 **싹이**(새싹). 안 한 일은 동그란 씨앗, 끝내면 목표 색으로 물들고 머리에 잎 두 장이 돋습니다. 데스크톱 24×24, 모바일 26×26. **테두리 없이 채웁니다.**

| 상태 | 모양 |
| --- | --- |
| 미완료 | 씨앗(`SPROUT_BODY`)을 `box`로 채움, 잎 없음 |
| 완료 | 씨앗 + 잎(`SPROUT_LEAVES`)을 목표 색으로 채움, 체크 표시는 `checkColor(goalColor)`, 굵기 2.7(24 기준). 잎은 체크 표시와 함께 튀어나옵니다 |
| 건너뜀(루틴) | 씨앗을 `box`로 채움, 가운데 짧은 가로선 `muted`, 잎 없음 |
| 누르는 중 | `scale(0.86)` |
| 대비 높이기 켬 | 미완료·건너뜀 씨앗에 1.4px `muted` 외곽선 (DESIGN.md §7) |

### 모양 정의 (24×24 viewBox)

모든 플랫폼이 같은 path를 씁니다. `@nodii/core`에 상수(`SPROUT_BODY`, `SPROUT_LEAVES`, `SPROUT_CHECK`, `SPROUT_DASH`)로 두고 데스크톱·모바일이 가져다 씁니다.

```text
SPROUT_BODY   = M3.70 14.20a8.30 8.30 0 1 0 16.60 0a8.30 8.30 0 1 0 -16.60 0z
SPROUT_LEAVES = M12.00 6.40C12.00 4.40 12.90 2.80 15.10 2.30C15.50 4.60 14.20 6.20 12.00 6.40zM12.00 6.40C12.00 4.70 11.20 3.40 9.40 3.00C9.10 4.90 10.10 6.20 12.00 6.40z
SPROUT_CHECK  = M7.6 14.8l2.8 2.8c1.7-3.2 3.9-5.6 6.4-7.4   (stroke, 둥근 끝·둥근 이음)
SPROUT_DASH   = M8.4 14.2h7.2                          (건너뜀)
도장 숫자      = x 12, 기준선 y 17.6, 글자 9.5 / 800 (가운데 정렬)
```

- 씨앗 중심은 (12, 14.2)로 박스 중심보다 아래입니다. 위쪽 여백은 잎 자리이고, 체크·숫자는 이 path 기준 좌표 그대로 올리면 씨앗 가운데에 앉습니다.
- 데스크톱 체크는 `<button>` 안에 인라인 SVG로 그립니다. 버튼 자체는 투명 24×24라서 키보드 포커스 링이 모양에 잘리지 않습니다. 등장 애니메이션은 체크 path에 `transform-box: fill-box`.
- 모바일은 `react-native-svg`의 `Path`로 그립니다(새 의존성 추가 금지 원칙상 이미 있는지 먼저 확인하고, 없으면 보고).
- 이 실루엣이 나중의 마스코트 몸입니다. 모양을 바꾸면 마스코트도 같이 바뀌므로 path를 임의로 손보지 않습니다.

- 제목은 15px(모바일 16px). 완료면 `ink-2`, 건너뜀이면 `muted`. **취소선은 긋지 않습니다**(v2).
- 루틴도 할 일과 같은 모양입니다. 하루 목록에서는 구분 아이콘이나 꼬리표를 두지 않습니다(ROUT-05, 요구사항 v1.3).
- 건너뛴 루틴은 제목 뒤에 "건너뜀" 12px/700 `muted` 글자를 붙입니다.
- 할 일에는 별도 드래그 손잡이를 표시하지 않습니다. 행 전체를 위아래로만 드래그하면 같은 목표 안에서 순서를 바꾸고, 키보드 포커스 후 Space·방향키로도 옮길 수 있습니다(TODO-06). 드래그할 수 없는 루틴에도 손잡이 자리의 빈 여백을 두지 않습니다.
- 줄 오른쪽 끝의 `⋯` 버튼은 평소 투명, 호버·포커스 때 나타납니다. 줄 어디서든 우클릭해도 같은 메뉴가 열립니다.

## 목표 이름표 (`GoalChip`)

- 높이 34(모바일 36), 반지름 999, 좌우 여백 11/12, 바탕 **`chip`**, 굵기 800.
- 안쪽 순서: **`GoalMark`**(v3: 나만 = 10px 목표 색 점, 맞팔로우·팔로워 = 범위 아이콘) · 이름(글자색 `goalInk(color, chip)`) · `+`(14px, `ink`). 점과 글자 사이 7px(아이콘이면 6px).
- 친구의 하루를 볼 때는 `GoalMark`를 범위와 상관없이 점으로 그리고 `+`를 붙이지 않습니다(SOC-24, SOC-32).
- 하루 목록에서는 이름표 **자체가 추가 버튼**입니다. 누르면 그 목표의 입력 줄이 열립니다(TODO-01). `+`는 하루 목록에서만 붙입니다.
- 회색 묶음(`chip`) 안에 놓일 때(목표 관리·루틴 관리 줄)는 이름표 바탕을 `bg`로 바꿔 알약 모양이 보이게 합니다.
- 고른 상태(루틴 편집의 목표 고르기)는 같은 모양에 목표 색 2px 안쪽 링.
- 보관한 목표의 이름표는 같은 모양에 불투명도 55%.

## 할 일 입력 줄

- 체크 자리에 빈 체크(`box` 채움)를 두고, 그 옆에 입력칸, 오른쪽 끝에 "Enter로 추가, Esc로 닫기" 12px `muted`(데스크톱만).
- 줄 바탕은 `chip`, 반지름 14. 캐럿 색은 목표 색.
- Enter로 추가한 뒤에도 입력 줄은 열려 있습니다(연속 입력). IME 조합 중 Enter는 무시합니다(`isComposing`).
- 비어 있거나 공백만 있는 상태에서 Enter를 누르면 아무것도 추가하지 않고 입력 줄을 닫습니다.
- 닫기는 Esc **또는 입력 줄 바깥을 클릭**입니다(v1.2). 바깥을 클릭해 닫을 때 적고 있던 글자는 저장하지 않고 버리며, 포커스는 클릭한 곳에 그대로 둡니다. Esc로 닫으면 포커스는 목표 이름표로 돌아갑니다.

## 캘린더 칸

한 칸 = 도장(위) + 날짜 숫자(아래), 높이 62(모바일 주간 78·월간 66), 반지름 14.
모바일 월간은 설정한 주 시작 요일에 따라 그달 1일·말일이 포함된 **4~6주만** 표시합니다. 월별 데이터 조회·캐시는 42칸을 유지하며 데스크톱 월간의 6주 표시는 바꾸지 않습니다. 모바일 날짜 선택 시트도 같은 표시 규칙을 씁니다.
도장도 **싹이** 모양, 30×30(데스크톱·모바일 공통). 다 끝낸 날만 잎까지 그리고 나머지는 씨앗만. **하나라도 끝낸 날은 끝낸 목표 색으로 씨앗을 채웁니다**(2026-10-27 결정). 잎과 체크는 다 끝낸 날에만 돋으므로, "조금 했다"와 "다 했다"가 모양으로 구분됩니다. 데스크톱은 `clip-path: path()`(30px로 늘린 path) 또는 인라인 SVG, 모바일은 SVG.

| 상황 | 도장 |
| --- | --- |
| 모두 끝냄 | 씨앗 + 잎을 `stampFill(그날 나온 목표 색)`로 채움 — 목표 색을 135° 대각선 블록으로 나눠 칠함(최대 4색), 흰 `SPROUT_CHECK`(1px 그림자로 밝은 색 위에서도 읽힘) |
| 일부 끝냄 (남음 있음) | 씨앗만 `stampFill(그날 끝낸 항목의 목표 색)`로 채움, 잎·체크 없음. 남은 개수는 흰 글자(1px 그림자). 끝낸 색 중 하나라도 `checkColor`가 먹색이면(옐로·라임 등) 숫자도 `checkColor`의 먹색. 날짜(지난날·오늘·앞날)와 상관없이 같습니다 |
| 지난날·오늘에 남음 (하나도 못 끝냄) | `box` 바탕, 남은 개수 12/800 `ink-2`(오늘은 `ink`) |
| 앞날에 예정 (하나도 못 끝냄) | `stamp-soft` 바탕, 남은 개수 `muted` |
| 항목 없음 | `stamp-soft`로 채운 빈 씨앗 (남은 개수가 있는 날과 같은 크기) |

- 숫자: 선택한 날은 `ink` 알약에 흰 글자, 오늘(선택 안 됨)은 1.5px `ink` 테두리 알약, 나머지는 600 굵기 평소 색(일·토는 `sun`/`sat`), 다른 달은 불투명도 40%.
- 남은 개수 = 그날의 할 일 + 루틴 중 미완료(건너뛴 루틴 제외) — CAL-02.
- 도장 자리는 **항상 같은 크기**로 그립니다. 빈 날에도 상자가 있어야 숫자가 어느 날짜의 것인지 바로 읽힙니다.
- "도장에 쓰는 목표 색"은 다 끝낸 날이든 일부 끝낸 날이든 그날 **완료한 항목들의 목표 색**입니다(건너뛴 루틴·미완료 항목의 목표 제외). 색 순서는 목표 정렬 순서를 따릅니다.
- 접근성 이름은 그대로("9월 16일, 남은 항목 2개"). 색은 보조 정보입니다.

## 주간 스트립 (`WeekStrip`, 좁은 창)

- 창이 좁을 때 월간 캘린더를 대신합니다. 한 줄 7칸, 칸 모양과 도장 규칙은 캘린더 칸과 같습니다.
- 왼쪽에 `2026년 9월` 라벨(800), 오른쪽에 원형 `‹ ›`. `‹ ›`는 **한 주씩** 이동합니다. v3에서 `[오늘]` 버튼은 없어지고 라벨을 누르면 오늘로 갑니다(D30, 아래 "월 제목 버튼").
- 주 시작 요일은 설정을 따릅니다(CAL-05). 선택·오늘 강조는 월간과 같습니다.

## 하루 메뉴 (`DayMenu`)

- 하루 목록 오른쪽 위 버튼에서 열리는 메뉴입니다. v3에서 버튼 아이콘은 `⋯` 대신 **슬라이더 아이콘**이고(D22), 친구의 하루를 볼 때는 버튼을 숨깁니다(SOC-32). 항목은 위에서부터: 지난 미완료 할 일 N개 가져오기 · 미완료 할 일 다른 날로 옮기기 · (구분선) · 미완료 할 일 전체 삭제(`danger`).
- 쓸 수 없는 항목은 숨기지 말고 비활성으로 두고, 이유를 보조 설명으로 답니다(예: "오늘 화면에서만 쓸 수 있어요").

## 컨텍스트 메뉴

- 너비 220(하루 메뉴 272), 반지름 14, `surface` 바탕, 메뉴 그림자. 항목 높이 34, 항목 반지름 8.

## v3 소셜 (2026-11-11)

근거: `docs/16-v3-social-plan.md`. 시안 이름은 디자인 캔버스 아트보드 이름입니다. 두 앱이 같은 이름·같은 props로 하나씩만 둡니다(`apps/desktop`과 `apps/mobile` 각각에 한 벌).

### `GoalMark` — 목표 동그라미·공개 범위 아이콘 (SOC-24, D16)

- props: `color`(목표 색), `visibility`(`private`·`mutual`·`followers`·`public`), `size`(기준 동그라미 지름), `plain`(친구 화면처럼 범위와 상관없이 점으로).
- `private`·`plain` → 지름 `size` 원, 채움 = 목표 색. `mutual` → 사람 둘, `followers` → 사람 하나, 둘 다 채운 모양이고 색 = `goalInk(color, chip, isDark)`. 아이콘 크기는 `size × 1.7`(10 → 17, 9 → 15).
- `public`은 v3 화면에 나오지 않지만 값이 오면 지구 아이콘 대신 **점**으로 그립니다(다음 업데이트에서 아이콘 추가, D3).
- 오늘 화면 이름표, 목표 관리·보관함·추가·편집, 할 일·루틴 메뉴 시트 머리말, 루틴 관리·루틴 편집의 목표 이름표가 모두 이것을 씁니다. 캘린더 도장·체크·루틴 범위 미니 캘린더는 바꾸지 않습니다.
- 접근성: 이름표 레이블에 범위를 붙입니다. "공부에 할 일 추가, 맞팔로우 공개" · 나만은 "나만 보기".

### `Avatar` (SOC-01, D23)

- props: `photoUrl?`, `size`, `selected?`, `label`(접근성 이름). 사진이 없으면 기본 싹이(`tokens.md` §9). 고른 상태는 `bg` 간격 + `ink` 테두리.
- 아바타 줄·"오늘에 보일 사람"·프로필 머리·알림 줄·목록·검색 결과가 모두 이것을 씁니다.
- 사진을 불러오지 못하면 조용히 기본 이미지를 보여 줍니다(오류 토스트 없음).

### 아바타 줄 (`AvatarRow`, SOC-30·35, 시안 `SocialFriendsA1`·`DeskSocialFinal`)

- 칸: `Avatar` + 이름. 맨 앞 "나", 그 뒤 "오늘에 보일 사람"에서 켠 팔로잉을 정한 순서대로, 마지막 칸은 **≡ 목록**(테두리만 있는 원 `line-2` 1.5px 안쪽 선 + 가운데 ≡ `ink-2` + 이름 "목록").
- 모바일은 가로 스크롤(목록 칸도 같이 스크롤), macOS는 창 맨 위 전체 폭이고 넘치면 가로 스크롤. 고정되는 칸은 없습니다.
- 칸은 `role="button"` + `aria-pressed`. 레이블: "내 하루, 보는 중" / "민수의 하루 보기".

### 월 제목 버튼 (D30)

- 접근성 레이블 "2026년 9월, 누르면 오늘로 이동", macOS 툴팁 "오늘로 이동", 데스크톱 포커스 링은 다른 버튼과 같습니다. `[오늘]` 회색 알약 버튼은 없앱니다.

### `FollowButton` (D25)

| 관계 | 문구 | 모양 |
| --- | --- | --- |
| 내가 팔로우 안 함, 상대도 안 함 | 팔로우 | 주요(`ink` 바탕) |
| 내가 팔로우 안 함, 상대는 나를 팔로우 | 맞팔로우 | 주요(`ink` 바탕) |
| 내가 팔로우 중 | 팔로잉 | 보조(`chip` 바탕) |

- 크기: 목록·알림 줄 높이 32 / 프로필 머리 36(펼침에서 폭 140). 누르는 동안 비활성 + 낙관적 업데이트.
- [팔로잉]을 누르면 언팔로우 확인 창(SOC-11): "민수님을 언팔로우할까요?" + 맞팔로우 목표도 더 이상 볼 수 없다는 안내 + [취소] [언팔로우].
- 관계는 서버가 준 두 불리언(`iFollow`, `followsMe`)에서 `@nodii/core`의 순수 함수 하나로 고릅니다.

### 탭바 (`TabBar`, D13·D20)

### 알림 줄 (`NotificationRow`, SOC-55·56)

- 40 `Avatar` · 문장(14~15, 이름만 800) · 아래 12 `muted` 시간 · 오른쪽 동작. 줄 최소 높이 58~64, 안 읽음 표시 없음.
- 오른쪽 동작: 친구 완료 = 펼치기 `⌄`(32 원, 열리면 `⌃`), 반응 = 반응받은 목표의 싹이 체크(22), 새 팔로워 = `FollowButton`(작은 크기).
